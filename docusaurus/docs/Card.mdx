# Tarjeta de Detalles del Producto (`<Card />`)

El componente `Card` es la unidad visual principal para mostrar productos en el catálogo. Está diseñado siguiendo criterios de accesibilidad y optimización de carga (Lazy Loading).

## Propiedades (Props)

| Propiedad | Tipo | Obligatorio | Descripción |
| :--- | :--- | :--- | :--- |
| `nombre` | `string` | Sí | Nombre del producto. Se usa para el título y el atributo `alt`. |
| `foto` | `string` | Sí | URL de la imagen del producto. |
| `children` | `node` | No | Descripción o contenido adicional que aparecerá bajo el título. |

---
