# Tarjeta de Producto (`<Card />`)

El componente `Card` es el bloque de construcción fundamental de la interfaz de **Basket Mall**. Se utiliza para representar visualmente cualquier recurso (productos, categorías o artículos de blog) de forma aislada y accesible.
